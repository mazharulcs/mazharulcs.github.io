## Run Locally

To view or modify this website on your computer:

1. Clone the repository:

   ```bash
   git clone https://github.com/mazharulcs/mazharulcs.github.io.git
   ```

2. Open the project folder:

   ```bash
   cd mazharulcs.github.io
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
