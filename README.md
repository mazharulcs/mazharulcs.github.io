# Mazharul Islam Portfolio

Responsive personal portfolio made with plain HTML, CSS, and JavaScript. Includes a centered desktop navigation, mobile menu, and a persistent light/dark theme toggle.

## Files
- `index.html`: page content and navigation
- `style.css`: layout, responsive styles, and light/dark theme variables
- `script.js`: theme toggle, saved theme preference, mobile navigation, current year
- `assets/profile.jpg`: put your portrait here

## Customize
Edit `index.html` to update your name, biography, email, education, experience, projects, publications, and links. Add your photo as `assets/profile.jpg`. Change colors in the `:root` and `html[data-theme="dark"]` sections of `style.css`.

## GitHub Pages
Copy the files into the root of your existing `mazharulcs.github.io` repository, preserving its `.git` directory. Commit and push to `main`. In Settings → Pages, choose Deploy from a branch → `main` → `/ (root)`, unless you use a different existing deployment workflow.
